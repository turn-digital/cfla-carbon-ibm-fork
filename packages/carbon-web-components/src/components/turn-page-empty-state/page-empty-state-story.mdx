# Page empty state

## Apraksts

- argument title - Virsraksts
- slot text - Apraksts
- slot button - Poga
- slot link - Saite

## Dizaina un UX komentāri

Tiek ievietos, kad lapai nav satura

## Getting started

### JS (via import)

```import
<script type="module" src="https://demo.turn.lv/cfla_dist/turn-page-empty-state.min.js"></script>
```

### HTML

#### Mani projekti

```html
<cds-page-empty-state title="Mani projekti">
  <span slot="content">
    Šajā sadaļā tiek atspoguļoti projekti, kuros ir noslēgts līgums. Šobrīd Jums
    vēl nav neviens noslēgts līgums par projekta īstenošanu. Atlases procesā
    esošie projektu iesniegumi ir pieejami sadaļā "Projektu iesniegumi".
  </span>
  <span slot="button">
    <cds-button href="https://www.ibm.com"> Button </cds-button>
  </span>
  <span slot="link">
    <cds-link href="https://www.ibm.com"> Link </cds-link>
  </span>
</cds-page-empty-state>
```
