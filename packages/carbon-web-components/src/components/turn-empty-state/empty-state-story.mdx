# Empty state

## Apraksts

Komponents tiek lietots, lai attēlotu situāciju, kad tabulā vēl nav pievienoti
ieraksti. Visbiežāk tas parādās, kad lietotājs pirmo reizi mijiedarbojas ar
konkrēto saturu.

## Anatomija

- Paziņojuma teksts - paskaidro, ka šobrīd tabulā nav pievienots neviens
  ieraksts, teksts tiek pielāgots atbilstoši tabulas saturam.
- Darbības poga - pamudinājums darbībai, aktivizē iespēju pievienot ierakstu
  tabulai.

## Dizaina un UX komentāri

Darbības poga var nebūt, ja tabulā nav iespējams pievienot saturu, bet tad
tekstā jāpaskaidro, kāpēc tas nav iespējams vai kur to var izdarīt.
