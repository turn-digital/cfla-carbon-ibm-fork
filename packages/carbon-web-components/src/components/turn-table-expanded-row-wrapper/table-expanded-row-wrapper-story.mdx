# table-expanded-row-wrapper

## Apraksts

Komponents tiek lietots, lai attēlotu paplašināmo rindu Carbon tabulā,
nodrošinot strukturētu un pielāgojamu satura izkārtojumu. Tas pievieno atstarpes
augšpusē, apakšā un labajā pusē.

## Getting started

### JS (via import)

```javascript
<script
  type="module"
  src="https://demo.turn.lv/cfla_dist/turn-table-expanded-row-wrapper.min.js"></script>
```

### HTML

```html
<cds-table-expanded-row>

</cds-table-expanded-row>
```
