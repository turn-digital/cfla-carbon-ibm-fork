# table-expanded-row-wrapper

## Apraksts

Ietvara (wrapper) komponents. Tiek lietots, lai nodrošinātu vienādas atkāpes
tabulas izvērsuma rindā. Pēc noklusējuma Carbon dizaina sistēma izvērsuma rindā
nepiemēro atkāpes satura augšpusē, apakšā un labajā pusē, kas var radīt vizuālas
problēmas. Piemēram, ievietojot tabulu tabulā, apakšējā tabula labajā pusē tieši
pieguļ augšējai, radot nesakārtotu izskatu. Šis komponents automātiski pievieno
nepieciešamās atstarpes, novēršot nepieciešamību katru reizi manuāli izmantot
Divider komponentu.
