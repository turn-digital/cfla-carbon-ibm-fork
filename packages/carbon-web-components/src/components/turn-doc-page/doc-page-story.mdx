# Doc-page

## Apraksts

Veidalapa

## Anatomija

cds-doc-page - main wrapper

- arg withTabs - add if tabs needed
- slot header - header content
- slot tabs - tabs if needed
- slot content - slot for main content (tab wrapper + cds-doc-page-tab-content)

cds-doc-page-tab-content - component for all real content inside

- arg withSidenav - add if content will have sidenav
- arg withBreadcrumbs - add if content will have breadcrumbs
- arg withPrintDownload - add if content will have print-download component
- slot tab-sidenav - slot for desktop sidenav
- slot tab-sidenav-mobile - slot for mobile nav
- slot tab-print-download - slot for print-download component
- slot tab-breadcrumbs - slot for breadcrumbs
- slot tab-content - slot for all main content (tables, labels, ..)

## Dizaina un UX komentāri

Laukums, kurā tiek ievietotas citas komponentes.
