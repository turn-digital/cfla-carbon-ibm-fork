# Project card

## Apraksts

Projekta kartīte - attēlo svarīgāko informācija par projektu.

## Anatomija

- CardTitle - Projekta nosaukums
- CardTitleUrl - Projekta saite
- ProjectCostTitle - Nosaukums, kas redzams virs izmaksām, projekta kartītē -
  "Projekta kopējās izmaksas EUR"
- projectCostInfo - Summa. Projekta kopējās izmaksas EUR.
- ProjectDateTitle - Nosaukums, kas redzams virs datuma, projekta kartītē, tas
  ir "Projekta īstenošanas termiņš"
- ProjectDateInfo - Datumi. Projekta īstenošanas periods
- ProjectId - Projekta identifikācijas numurs (augšējā kreisajā stūrī)
- supervisorAuthority - Uzraugošās iestādes nosaukums
- organization - Projekta iesniedzēja nosaukums
- tagTitle - Statuss. Norāda, kādā statusā ir projekts, piemēram, "Apstiprināts
  ar nosacījumu"
- Overflow menu - Darbības, kuras var veikt ar kartīti, piemēram, atvērt, dzēst
  u.tml.

## Dizaina un UX komentāri

Tiek lietota vērtējuma pārskatīšanas izveidošanas skatā, projekta iesniegumā,
kur tiek norādīti saistītie projekti, manu projektu sarakstā un projekta
iesniegumu sarakstā.
